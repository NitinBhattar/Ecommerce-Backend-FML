# 🛒 Order Service

Manages order creation and order processing for the E-Commerce Backend.

### APIs

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/order/create` | Create a new order |

### Tech Stack

Java · Spring Boot · Spring Data JPA · MySQL · Apache Kafka · OpenFeign

### Run Locally

```bash
./mvnw spring-boot:run
```

**Port:** `8084`
