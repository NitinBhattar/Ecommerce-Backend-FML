# 🚪 API Gateway

Centralized entry point for the E-Commerce Backend, built with Spring Cloud Gateway.

### Features
- JWT authentication and role-based authorization
- Request routing to microservices
- Eureka service discovery
- Authenticated user header propagation

### Tech Stack
Java · Spring Boot · Spring Cloud Gateway · Eureka · JWT

### Run Locally
```bash
./mvnw spring-boot:run
```

**Port:** `8081`

📚 Refer to individual microservice READMEs for API endpoints.
